# 🎙️ Voice Authenticity Dataset Studio (React + FastAPI)

A modern full-stack web app built with **React (Vite)** and **FastAPI** that **collects genuine human voice recordings** and **generates synthetic voice samples** using open-source TTS engines, then pushes everything to a Hugging Face Hub dataset for **voice-cloning fraud detection research**.

---

## 🔬 Purpose

Voice cloning technology is increasingly used in phone fraud. This tool builds a labeled dataset of:
- **Human voice samples** — real people reading scripted prompts in English (Indian), Hindi, and Marathi
- **Synthetic voice samples** — generated by multiple TTS engines (Edge-TTS, Coqui XTTS, Bark)
- **Cloned voice samples** — XTTS voice cloning from consented human samples

This dataset trains and evaluates AI detectors that distinguish real voices from AI-generated ones.

## 🚀 Quick Start

### Prerequisites
- **Python 3.10+**
- **Node.js 18+ & npm**
- **ffmpeg** installed and on your system PATH (or auto-detected via ffmpeg-downloader)

---

### 1. Installation

#### Backend Setup (Python)
```bash
# In the project root directory
pip install -r requirements.txt
```

#### Frontend Setup (React)
```bash
cd frontend
npm install
cd ..
```

---

### 2. Configuration

1. Copy the environment template:
   ```bash
   cp .env.example .env
   ```

2. Edit `.env` with your values:
   ```env
   # Hugging Face token with "write" permission
   HF_TOKEN=hf_your_token_here

   # Dataset repository name on HF Hub
   HF_DATASET_REPO=yourusername/voice-authenticity-dataset

   # Password for the admin panel
   ADMIN_PASSWORD=your_secure_password
   ```

---

### 3. Run the App

Open **two terminal windows**:

#### Terminal 1 — Backend (FastAPI):
```bash
uvicorn backend.main:app --reload --port 8000
```
*API will run at `http://localhost:8000` (Docs at `http://localhost:8000/docs`)*

#### Terminal 2 — Frontend (React + Vite):
```bash
cd frontend
npm run dev
```
*Web studio will open in your browser at `http://localhost:5173`*

## 📱 How It Works

### For Contributors (Public)
1. **Consent** — Read and agree to recording terms (18+ age + voice usage consent)
2. **Profile** — Quick anonymous info (age range, gender, region, environment — no PII)
3. **Record** — Read 9 short sentences displayed one at a time (3 in English, 3 in Hindi, 3 in Marathi) into your browser mic
4. **Upload** — All 9 clips are batch-uploaded to the private HF dataset
5. **Done!** — Option to record another session

### For Admins (Password-protected)
- **📊 Statistics** — View total contribution counts, breakdowns by language and source
- **🤖 Synthetic Generation** — Generate TTS audio across engines and voices for all prompts
- **🧬 Voice Cloning** — Clone consented human samples using Coqui XTTS v2

## 🤖 TTS Engines

| Engine | Type | Languages | Voices | Cloning | Install |
|--------|------|-----------|--------|---------|---------|
| **Coqui TTS** | Local neural | English, Hindi, Marathi | XTTS speakers + VITS (109 EN) | ✅ XTTS v2 | `pip install coqui-tts` |
| **Edge-TTS** | Cloud neural | English, Hindi, Marathi | 2-3 per language | ❌ | `pip install edge-tts` |
| **Bark** | Local generative | English | 10 presets | ❌ | `pip install git+https://github.com/suno-ai/bark.git` |

> **Note:** Coqui TTS requires accepting the CPML license on first run (type `y` in terminal).
> Bark requires ~12 GB VRAM for full model; use `SUNO_USE_SMALL_MODELS=True` for smaller GPUs.

## 📂 Adding New Languages / Prompts

Edit [`config/prompts.json`](config/prompts.json):

```json
{
  "new_language": [
    {
      "id": "nl_01",
      "romanized_text": "Your romanized text here.",
      "type": "pangram",
      "note": "Read naturally at a comfortable pace."
    }
  ]
}
```

Then add the language to `LANGUAGES` in [`config/settings.py`](config/settings.py):

```python
LANGUAGES = {
    ...
    "new_language": "Display Name",
}
```

For Edge-TTS support, also add voice mappings in `EDGE_TTS_VOICES` and `EDGE_TTS_LANG_CODES`.

## 🔒 Privacy & Consent Model

- **No PII collected** — no names, emails, phone numbers, or IP addresses
- **Anonymous UUID** — each session gets a random contributor ID
- **Explicit consent** — two checkboxes required before any recording
- **Consent covers cloning** — the consent text explicitly mentions that recordings may be used as reference for generating synthetic voice pairs within this project
- **Private dataset** — pushed to HF Hub with `private=True`
- **No authentication for contributors** — frictionless recording experience
- **Admin-only access** — synthetic generation and stats require password

## 📊 Dataset Schema

Each row in the HF dataset contains:

| Column | Type | Description |
|--------|------|-------------|
| `contribution_id` | string | UUID for human sessions, `synth_*` for generated |
| `source` | string | `human` or `synthetic` |
| `language` | string | Language key (e.g., `hindi`, `tamil`) |
| `prompt_id` | string | Prompt identifier (e.g., `hi_01`) |
| `prompt_text_romanized` | string | The romanized text that was read/synthesized |
| `age_range` | string | Contributor's age range (human only) |
| `gender` | string | Contributor's gender (human only) |
| `region` | string | Contributor's region (human only) |
| `environment` | string | Recording environment (human only) |
| `tts_engine` | string | TTS engine name (synthetic only) |
| `voice_id` | string | Voice/speaker ID (synthetic only) |
| `audio` | Audio | 16 kHz mono WAV audio |
| `duration_seconds` | float | Clip duration |
| `submitted_at` | string | ISO 8601 timestamp |

Data is split into `human` and `synthetic` splits for clean separation.

## 🛠️ Troubleshooting

### Microphone not working
- Ensure your browser has microphone permissions (check URL bar for 🎤 icon)
- Use **Chrome or Edge** for best compatibility
- The app must be served over **HTTPS** or **localhost** (browser security requirement)

### HF upload failures
- Check your `HF_TOKEN` has **write** permission
- Verify `HF_DATASET_REPO` format: `username/dataset-name`
- Failed uploads are saved to `local_fallback/` — upload manually later

### TTS model download
- Coqui models download automatically on first use (~2-4 GB)
- First run prompts for CPML license acceptance in the terminal
- Set `CUDA_VISIBLE_DEVICES=""` to force CPU if GPU has issues

### ffmpeg not found
- `pydub` requires ffmpeg for audio format conversion
- Install via your package manager (see Prerequisites above)
